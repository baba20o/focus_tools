128	## 🧠 LLM Integration Patterns
129	
130	### Pattern 1: **Profile-First (Fast Path - 80% of queries)**
131	
132	```python
133	def pattern_profile_first(question: str) -> dict:
134	    """
135	    Use when question maps to known profile.
136	    Latency: 8-12s | Cost: $0.01 | Accuracy: 90%+
137	    """
138	    # Rule-based routing
139	    profile = match_profile(question)  # Simple keyword rules
140	    
141	    # Run probe
142	    bundle = focus_probe.run(
143	        keyword=extract_keyword(question),
144	        profile=profile,
145	        budget_tokens=8000
146	    )
147	    
148	    # Synthesize
149	    if bundle.files_with_hits >= 3:
150	        return llm.generate(question, bundle)
151	    else:
152	        return pattern_synthesize(question)  # Fallback
153	```
154	
155	**When to use:**
156	- Question contains clear intent keywords ("launch", "teleop", "config")
157	- Similar questions have been answered before
158	- Speed is critical
159	
160	**Examples:**
161	- "How do I launch X?"
162	- "What does function Y do?"
163	- "Where is Z configured?"
164

167	### Pattern 2: **Synthesize (Flex Path - 15% of queries)**
168	
169	```python
170	def pattern_synthesize(question: str) -> dict:
171	    """
172	    Use when no profile matches or question is unusual.
173	    Latency: 12-18s | Cost: $0.02 | Accuracy: 85%+
174	    """
175	    # LLM generates probe parameters
176	    params = llm.synthesize_probe_params(
177	        question=question,
178	        available_profiles=list_profiles(),
179	        guidelines=PROBE_SYNTHESIS_RUBRIC
180	    )
181	    
182	    # Run probe with synthesized params
183	    bundle = focus_probe.run(**params)
184	    
185	    # Quality gate
186	    if bundle.is_weak():
187	        # Broaden once
188	        relaxed = relax_filters(params)
189	        bundle = focus_probe.run(**relaxed)
190	    
191	    return llm.generate(question, bundle)
192	```
193	
194	**When to use:**
195	- No profile matches
196	- Novel question type
197	- Cross-domain query
198	
199	**Examples:**
200	- "Compare authentication methods across services"
201	- "Find all TODO comments in recent commits"
202	- "Which configs affect network latency?"
203

206	### Pattern 3: **Iterative Refinement (Complex Path - 5% of queries)**
207	
208	```python
209	def pattern_iterative(question: str) -> dict:
210	    """
211	    Use for complex multi-step investigations.
212	    Latency: 20-40s | Cost: $0.05 | Accuracy: 90%+
213	    """
214	    # Initial probe
215	    bundle1 = pattern_profile_first(question)
216	    
217	    # LLM decides: sufficient?
218	    decision = llm.evaluate_sufficiency(question, bundle1)
219	    
220	    if decision.sufficient:
221	        return llm.generate(question, bundle1)
222	    
223	    # Follow-up probe with refined params
224	    refined_params = llm.refine_probe(
225	        question=question,
226	        initial_bundle=bundle1,
227	        gaps=decision.gaps
228	    )
229	    
230	    bundle2 = focus_probe.run(**refined_params)
231	    
232	    # Merge context
233	    merged = merge_bundles(bundle1, bundle2)
234	    
235	    return llm.generate(question, merged)
236	```
237	
238	**When to use:**
239	- Initial results are close but incomplete
240	- Question has multiple sub-questions
241	- Cross-reference needed
242	
243	**Examples:**
244	- "How do components A and B interact?"
245	- "What's the full lifecycle of X?"
246	- "Find all dependencies of Y"
247

250	### Pattern 4: **Scoped RAG Fallback (Rare - 5% of queries)**
251	
252	```python
253	def pattern_scoped_rag(question: str) -> dict:
254	    """
255	    Use when structural search fails but directories are known.
256	    Latency: 25-50s | Cost: $0.08 | Accuracy: 75%+
257	    """
258	    # Try structural search first
259	    bundle = pattern_synthesize(question)
260	    
261	    if bundle.confidence < 0.5:
262	        # RAG scoped to directories probe found
263	        rag_chunks = rag.search(
264	            question,
265	            path_filter=bundle.path_prefixes,  # KEY: scoped to probe dirs
266	            k=5  # Small k, since scoped
267	        )
268	        
269	        # Merge
270	        context = {
271	            "structural": bundle.top_files,
272	            "semantic": rag_chunks
273	        }
274	        
275	        return llm.generate(question, context)
276	    
277	    return llm.generate(question, bundle)
278	```
279	
280	**When to use:**
281	- Structural search found directories but wrong files
282	- Question requires deep semantic understanding
283	- Concept-based search (not keyword)
284	
285	**Examples:**
286	- "What design patterns are used?"
287	- "Explain the error handling philosophy"
288	- "How is state managed?"

346	
347	### Probe Quality Score
348	
349	```python
350	def compute_quality_score(bundle: dict) -> float:
351	    """
352	    Returns 0.0-1.0 confidence score.
353	    """
354	    score = 0.0
355	    
356	    # File count (0.3 weight)
357	    files_score = min(bundle.files_with_hits / 5, 1.0) * 0.3
358	    
359	    # Cluster concentration (0.4 weight)
360	    # High when most files from same directory
361	    cluster_score = max_cluster_concentration(bundle.clusters) * 0.4
362	    
363	    # Token efficiency (0.2 weight)
364	    # High when token_estimate is reasonable
365	    token_score = (1.0 - min(bundle.token_estimate / 10000, 1.0)) * 0.2
366	    
367	    # Hit density (0.1 weight)
368	    # High when few files have many hits
369	    density_score = compute_hit_density(bundle.top_files) * 0.1
370	    
371	    return files_score + cluster_score + token_score + density_score
372	
373	def is_weak(bundle: dict) -> bool:
374	    """
375	    True if bundle likely needs broadening or RAG fallback.
376	    """
377	    return (
378	        bundle.files_with_hits < 3 or
379	        compute_quality_score(bundle) < 0.5 or
380	        max_cluster_concentration(bundle.clusters) < 0.3
381	    )
382	```

404	### Minimal Agent (Starter)
405	
406	```python
407	import focus_probe
408	import openai
409	
410	SIMPLE_PROFILES = {
411	    "launch": "teleop-scout",
412	    "doc": "doc-hunter",
413	    "config": "config-audit",
414	    "message": "msg-schema-hunter"
415	}
416	
417	def simple_agent(question: str, base_path: str) -> str:
418	    # Simple keyword routing
419	    profile = None
420	    for keyword, prof in SIMPLE_PROFILES.items():
421	        if keyword in question.lower():
422	            profile = prof
423	            break
424	    
425	    # Run probe
426	    bundle = focus_probe.run(
427	        keyword=extract_first_word(question),
428	        pattern=question,  # Use question as pattern
429	        base=base_path,
430	        profile=profile,
431	        top_files=8,
432	        peek=True,
433	        budget_tokens=8000
434	    )
435	    
436	    # LLM synthesis
437	    prompt = f"""
438	    Question: {question}
439	    
440	    Evidence:
441	    {format_bundle(bundle)}
442	    
443	    Answer the question using only the evidence. Cite file:line.
444	    """
445	    
446	    return openai.chat(prompt)
447	```

451	### Production Agent (Full Featured)
452	
453	```python
454	class FocusAgent:
455	    def __init__(self, config_path: str, cache_dir: str):
456	        self.config = load_config(config_path)
457	        self.cache = CacheLayer(cache_dir)
458	        self.analytics = AnalyticsLogger()
459	        
460	    def answer(self, question: str, base_paths: List[str]) -> dict:
461	        # Route
462	        route = self.route_question(question)
463	        
464	        # Check cache
465	        cache_key = self.cache.key(question, route, base_paths)
466	        if cached := self.cache.get(cache_key):
467	            return cached
468	        
469	        # Probe (with retry logic)
470	        bundle = self.probe_with_quality_gates(
471	            question=question,
472	            route=route,
473	            base_paths=base_paths
474	        )
475	        
476	        # Synthesize
477	        answer = self.synthesize_answer(question, bundle)
478	        
479	        # Log
480	        self.analytics.log({
481	            "question": question,
482	            "route": route,
483	            "bundle_stats": bundle.stats,
484	            "answer_quality": evaluate_answer(question, answer, bundle)
485	        })
486	        
487	        # Cache
488	        self.cache.set(cache_key, answer)
489	        
490	        return answer
491	    
492	    def probe_with_quality_gates(self, question, route, base_paths):
493	        """Implements Pattern 3: Iterative Refinement"""
494	        bundle = focus_probe.run(
495	            **route.params,
496	            bases=base_paths
497	        )
498	        
499	        if is_weak(bundle):
500	            # Try once with relaxed filters
501	            relaxed = relax_filters(route.params)
502	            bundle = focus_probe.run(**relaxed, bases=base_paths)
503	            
504	            if is_weak(bundle):
505	                # Scoped RAG fallback
506	                rag_chunks = self.rag.search(
507	                    question,
508	                    path_filter=bundle.path_prefixes
509	                )
510	                bundle = merge(bundle, rag_chunks)
511	        
512	        return bundle
513	```

605	## ♻️ Recent Retrieval Enhancements
606	
607	- Filename channel: focus_probe can promote candidate files by name using --file-name-regex/--file-name-globs with a configurable --filename-weight. This surfaces canonical targets (e.g., robot_actions.py, pyproject.toml) even when content matches are sparse.
608	- Include-all breadth: --include-all disables include globs in both content-first and normal modes, ensuring discovery breadth when needed.
609	- Authority weighting: default (mergeable) boosts for .msg/.idl/.srv/.urdf/.xacro/.toml/.xml and authority dirs (msg/srv/urdf/description/action).
610	- Structured extractors: peeks now include lightweight extractions when applicable:
611	  - .msg → extracted_msg_fields
612	  - .urdf/.xacro → extracted_urdf_joints
613	  These appear in the bundle/answer summary to guide LLMs without extra tokens.
614	
615	## 🧪 Mini‑LLM Switch & Debugging
616	
617	- Mini switch: Set FOCUS_USE_MINI=1 to enable mini‑LLM for classify/judge/rescoring; answer uses OPENAI_MODEL. With it off (default), classify is rule‑based and judge assumes sufficient.
618	- Debugging: pass --debug-llm to focus_llm (or set FOCUS_DEBUG_LLM=1) to print prompts/outputs to stderr. Traces are still written to results/traces/ when running via the benchmark.
619	- Run with `--debug` for troubleshooting
