# Contributing to Focus Tools

Thank you for your interest in contributing to Focus Tools!

## Development Setup

1. Clone the repository:
```bash
git clone https://github.com/baba20o/focus_tools.git
cd focus_tools
```

2. (Optional) Install PyYAML for config file support:
```bash
pip install pyyaml
```

3. Run tests:
```bash
python -m pytest tests/
```

## Code Style

- Follow PEP 8 style guidelines
- Use type hints where practical
- Keep functions focused and documented
- Add tests for new features

## Pull Request Process

1. Create a feature branch from `main`
2. Make your changes with clear commit messages
3. Add/update tests as needed
4. Update documentation if you're changing behavior
5. Submit a PR with description of changes

## Areas for Contribution

- **Language-specific parsers**: AST-aware search for Python, JavaScript, etc.
- **Profile marketplace**: Share and discover useful profiles
- **Performance optimizations**: Faster search algorithms
- **UI/UX**: Web interface or interactive CLI
- **Documentation**: Examples, tutorials, use cases

## Questions?

Open an issue or start a discussion on GitHub.
